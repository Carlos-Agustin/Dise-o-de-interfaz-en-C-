# Diseño-de-interfaz-en-C+
Descripción
Este programa gestiona un catálogo de estudiantes, programación en C++. A través de las operaciones de alta, baja, modificación y consulta, el sistema permite interactuar con la información de los estudiantes de manera ordenada, facilitando el registro, la actualización y la eliminación de datos. 

Tecnologías utilizadas
C++

Funcionalidades
- Registro de usuarios
- Altas y bajas
- Modificacion de informacion
- Consulta

Cómo ejecutar el proyecto
1. Clonar el repositorio
2. Importar el archivo a un editor de codigo
3. Ejecutar en servidor local
